# Glosario UX — LOF

Vocabulario canónico para textos orientados al usuario de LOF. El objetivo es
mantener un lenguaje consistente, no técnico, alineado con el modelo mental de
una cooperadora escolar de PBA.

## Principios

- Lenguaje en segunda persona, voseo argentino.
- No usar jerga de sistema ("schema", "refs", "widget", "landing", "carga consolidada").
- Priorizar términos que una persona de una cooperadora reconoce.
- Cuando un término técnico es inevitable, acompañarlo con una explicación breve.

## Términos canónicos

| Término UX | No usar | Contexto |
|---|---|---|
| Cierre de ejercicio | Cierre / Presentación | Menú, navegación |
| Análisis de tesorería | Resumen | Menú, navegación |
| Carga para rendir | Carga consolidada | Modalidad, wizard |
| Gestión completa | Gestión integral | Modalidad, wizard |
| Carga de movimientos por rubro | Carga PIA | Navegación interna |
| Aplicación dentro de Grist | Custom Widget | Onboarding, ayuda |
| Acerca de LOF | Ver landing | Sidebar de la app |
| Verificar estructura | Revalidar schema | Configuración |
| Reparar vínculos | Reparar refs | Configuración |
| Unificar personas repetidas | Deduplicar personas | Configuración |
| Estructura reparada | Schema reparado | Resultados |
| Vínculos corregidos | Refs corregidas | Resultados |
| Proyecto independiente, no oficial | (sin disclaimer) | Footer, sección confianza |
| miles de cooperadoras | 9.000 cooperadoras | Hero, descripción |

## Términos que se mantienen (reconocidos por el usuario)

- Cooperadora, Comisión Directiva (CD), Comisión Revisora de Cuentas (CRC)
- Socio, padrón, authorities, autoridades
- Asamblea (AGO, AGE, RCD)
- Ejercicio (fiscal)
- PIA (Planilla de Ingresos y Aportes)
- Nómina
- Memoria anual
- DIPREGEP, DGCyE (con aclaración de que LOF no es oficial)
- Tesorería, movimientos, caja, tablero de caja
- .lof (extensión de backup, ya explicada en contexto)
- Grist (nombre propio, explicado como "planilla inteligente gratuita")
