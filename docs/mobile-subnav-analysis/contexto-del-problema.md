# Contexto del problema

LOF usa `Tabs` (pestañas horizontales) como sub-navegación dentro de cada módulo. En mobile (375px), cuando hay 4-5 tabs con ícono + texto, cada tab ocupa ~120-140px y el total (~600-700px) desborda el viewport. El scroll horizontal funciona pero no es descubrible: el usuario no sabe que hay más opciones escondidas a la derecha.
